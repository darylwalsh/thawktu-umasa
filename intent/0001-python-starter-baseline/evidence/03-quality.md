## Q12: network blocking

Choose the maintained pytest-socket plugin rather than a custom fixture. Enable
`--disable-socket` for every test run. Unexpected warnings fail tests through
`filterwarnings = ["error"]`. The permanent regression test explicitly expects
both the plugin's diagnostic warning and `SocketBlockedError`, so it passes
without an unhandled warning or a broad warning filter.

A temporary test on `scratch/task03-acceptance` contained:

```python
import socket


def test_unhandled_socket():
    socket.socket()
```

`mise exec -- uv run --locked pytest --no-cov tests/test_socket_proof.py`
exited 1 with:

```text
FAILED tests/test_socket_proof.py::test_unhandled_socket - UserWarning: A tes...
1 failed in 0.02s
UserWarning: A test tried to use socket.socket.
```

This guard applies to Python socket calls within pytest. It is not an OS sandbox
for child processes or native libraries. The CLI subprocess runs only the local
installed module with fixed arguments. The complete clean-clone quality gate
also passed inside a network namespace with networking disabled.
